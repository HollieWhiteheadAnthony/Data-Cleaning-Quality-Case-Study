# Superstore Sales Data Dictionary

This section contains a data dictionary for a Superstore sales dataset. The goal was to document the structure, meaning, format, constraints, source, and usage of key dataset fields.

## Dataset

The data dictionary documents fields related to:

- Orders
- Customers
- Shipping
- Geography
- Products
- Sales

## Documentation Includes

For each field, the data dictionary identifies:

- Field name
- Data type
- Description
- Expected format
- Constraints
- Source system
- Usage in analysis or reporting

## Skills Demonstrated

- Data documentation
- Field definition
- Data governance basics
- Business rule documentation
- Dataset structure review
- Reporting and analysis preparation
