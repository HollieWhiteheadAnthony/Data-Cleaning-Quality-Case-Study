# Data Cleaning & Documentation Portfolio Case Study

This repository contains selected coursework examples demonstrating data cleaning, data preparation, and data documentation skills. The project is organized into three sections: an advanced retail sales cleaning workflow, an employee data quality review, and a Superstore sales data dictionary.

## Project Sections

### 1. Advanced Retail Sales Data Cleaning

This section contains a Python-based cleaning workflow using a retail store sales dataset. The workflow includes data inspection, missing value handling, data type correction, imputation, outlier detection, normalization, and export of a cleaned dataset.

Folder: `01-advanced-retail-sales-cleaning`

### 2. Employee Data Cleaning & Quality Review

This section contains a documentation-focused data quality review of a small synthetic employee dataset. It covers missing values, formatting issues, data type corrections, imputation decisions, and descriptive analysis.

Folder: `02-employee-data-cleaning-review`

### 3. Superstore Sales Data Dictionary

This section contains a data dictionary for a Superstore sales dataset. It documents field names, data types, descriptions, expected formats, constraints, source systems, and analysis/reporting usage.

Folder: `03-superstore-data-dictionary`
