# Employee Data Cleaning & Quality Review

This section contains a data quality review of a small synthetic employee dataset. The goal was to identify missing values, formatting issues, incorrect data types, and documentation needs.

## Dataset

The dataset contains employee information, including:

- Name
- Age
- Email
- Date of Birth
- Salary
- Years of Service
- Department

## Cleaning and Quality Review Tasks

This review includes:

- Missing value identification
- Column name standardization
- Formatting corrections
- Data type review and correction
- Email format cleanup
- Date of birth formatting
- Missing age imputation using date of birth
- Missing salary review using department and years of service
- Missing years of service handling
- Descriptive analysis of numerical and categorical fields

## Skills Demonstrated

- Data quality review
- Missing value handling
- Data type correction
- Data documentation
- Descriptive analysis
- Business rule thinking

## Notes

This section was completed as part of data analytics coursework and is included as a documentation-focused example of data cleaning and quality review.
